# Starrike

62 färdiga HTML-sidor med 47 produkter, lokala produktbilder och Starrikes ursprungliga logotyp. Ingen installation krävs.

## GitHub Pages
Packa upp ZIP-filen. Lägg innehållet i mappen starrike-github i repots rot. Aktivera GitHub Pages från huvudgrenen och rotmappen. Alla länkar och bilder fungerar även med ett reponamn i adressen.

## Funktioner
- Fullstor hero med Starrikes egen bild av bänken Holmen.
- Produktsökning, kategorifilter och prissortering.
- Produktsidor med bilder, mått, material, galleri och modellnavigering för Ymer.
- Sparade favoriter i webbläsarens lokala lagring.
- Berättelse, inspiration, företag, skötsel, dokument, journal och kundservice.

## Köpflödet
Knapparna Se & köp hos Starrike öppnar produktens ordinarie butikssida. Val av utförande, aktuell prissättning, beställning och betalning sker där. Ingen varukorg eller betalning hanteras av denna webbversion. Kontakt via telefon och mejl används för frågor och företagsdialog, inte som alternativ kassa.

Priser och produktfakta hämtades från starrike.se den 17 november 2026. Kontrollera alltid aktuellt pris, utförande, lager och villkor innan köp. En dubblett av Bord T 700 har tagits bort; en otillgänglig länk till Kil visas inte som köpbar produkt.

## Redigering
Innehåll finns i HTML-filerna. style.css styr utseendet. script.js sköter sökning, filter, sortering, gallerier, meny och favoriter. Favoriter lagras under starrike_favorites_v1. Inga externa analysskript är inbäddade. Typsnitten är systemtypsnitt.
